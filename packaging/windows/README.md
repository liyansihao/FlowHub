# FlowHub Windows 本地部署包

适用：Windows 11 64位，Docker Desktop（Linux容器 / WSL 2），建议至少8GB内存与10GB可用磁盘。首次安装需要联网下载运行环境与依赖。此包提供完整后台及原FlowB兼容模块，不是原生exe；不需要安装Chrome。

## 安装与启动

1. 从Docker官方网站安装Docker Desktop并启动，完成其WSL 2设置。第三方安装条款由设备所有者确认。
2. 将本目录解压到例如 `C:\FlowHub`，不要直接在ZIP内运行。
3. 双击 `Install.cmd`。它会构建容器并打开 http://127.0.0.1:38427/ 。失败时保留提示，勿删除数据卷。
4. 双击 `Admin.cmd` 查看本机生成的初始管理员账号密码。首次登录必须改密。通用包不携带原电脑的账号密码或店铺API密钥。
5. 可用 `Check.cmd` 检查 Python、Node、OCR语言包和引擎依赖。后续双击 `Start.cmd`、`Stop.cmd`、`Status.cmd`。Docker随登录启动时，未被停止的容器会自动恢复；电脑休眠、关机期间不能上架。

## 接通真实流程

- 店铺连接：录入你自己的毛子ERP Token、Ozon Client ID/API Key、毛子店铺ID、目标邮政仓库和水印，执行核验。
- 工作流：选择FlowB持续发现、FlowB 1688同款、毛子邮政利润，以及毛子ERP + Ozon回查。前三个模块密钥均填写该用户的ERP Token。兼容模块目前仅供管理员工作区使用，其他用户可接入自己的HTTPS/插件模块。
- 保持图片70/55、邮政、库存99，首轮候选上限100、实际提交上限3。首次不要直接不限量。
- 当前迁移流程在提交和补库存前继续核对原飞书明确下架清单。另建私密JSON文件：`{"token":"你的飞书访问令牌","app_token":"原Base的app token"}`，双击 `Feishu.cmd` 指定路径。不能获取该清单时会阻止写入，不会跳过。
- 首次候选为空是正常的：启动工作流后，发现模块通过ERP采集新候选，再进行1688识别。首次环境中的OCR改用Tesseract，需要与Mac实测比较识别结果。
- 已携带打包时的历史禁售/占用记录，防止重上历史商品；这些记录不替代迁移时的最终状态同步。

## 同店迁移要求

正式切换同一家店前：暂停旧电脑新增，回查完旧任务，重新同步最新禁售和SKU占用记录，再在Windows启用。不要让两台电脑同时给同一店铺自动补货/上架，离线ZIP不能协调跨电脑占用。当前Mac仍继续原有生产，本包不会远程停止它。

## 备份与恢复

`Backup.cmd` 会停止服务、备份整个data卷、再恢复服务，避免数据库与密钥不一致。备份包含店铺密钥，不能发给普通用户。数据库和master.key必须成套恢复；恢复前先只读核对Ozon真实结果，不能把历史未知任务当新商品重发。停止/重新构建容器不会删除数据卷，不要执行 `docker compose down -v`。

本地入口仅绑定127.0.0.1，不能直接作为公网多用户服务器；公网使用需另配HTTPS和访问控制。浏览器不能下载后台源码和日志，但拥有Windows/Docker管理员权限的人仍可检查部署文件。

## 验收状态

打包与静态检查在Mac完成。尚需在目标Windows完成：容器构建、依赖检查、ERP/飞书/店铺核验、真实3件可售与库存99回查、故障恢复及24小时连续运行。未经这些步骤，不宣称Windows实机验收通过。

Docker安装环境要求以官方文档为准：https://docs.docker.com/desktop/setup/install/windows-install/
