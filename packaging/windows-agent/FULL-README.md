# Windows 完整处理执行端 v3

## 安装与启动

1. 需要 Python 3.12（可与其他版本并存）。保留现有 FlowHub 设备配置。
2. 关闭旧 Start-Production.cmd 窗口。
3. 解压本包到本地目录，双击 Upgrade-Full.cmd。首次安装需要下载 PyTorch 等依赖，可能耗时较长。
4. 出现 `FlowHub v3 ready` 后保持窗口运行，并通知中控核验。
5. 以后使用 Start-Full.cmd。无需重新注册设备或输入接入码。

包内附带与 Mac 相同版本的 DINO 模型，避免首次运行重新下载模型。
程序检查 CPU 和 PyTorch 可用的 GPU，成功加载模型后才接受审核任务。
CUDA 是否可用取决于 Windows 的驱动及已安装 PyTorch 版本；没有可用 GPU 时用 CPU。

## 本机承担的工作

- 1688 图片找货源、DINO 同款相似度排序。
- Qwen 商品审核，沿用原算法和阈值。
- 毛子 ERP 查询、导入、库存操作，与审核进程独立运行。
- 支持 ERP 资料包提取；默认优先分发耗时的找货源和审核，轻量资料提取按中控策略启用。

Mac 继续负责商品分配、店铺选择、去重、利润确认、资料入库、发布前校验和最终结果入账。
执行端不持有生产数据库副本，不自行挑选商品。ERP 请求与 AI 审核凭证仅在执行时传入内存。
模型崩溃时仅重启计算进程；断网后继续回传已保存结果，不重放 ERP 写请求。

## 当前限制

Windows 的真实模型运行和自动审核须在升级后实机验收。
审核最多同时运行一个重计算任务，并行保留一个 ERP 执行进程。
增加机器不会增加毛子或 AI 服务本身的账号额度。
本版本由窗口运行，关机/关窗口停止；登录自启配置应在实机验收通过后再设置。
