# Windows 真实上架执行端升级

1. 关闭旧的 Start.cmd 窗口。
2. 解压本包，双击 Upgrade-Production.cmd。保留现有接入凭证，无需重新输入接入码。
3. 出现 `FlowHub production agent v2 ready` 后保持窗口运行，并通知 Mac 中控。
4. Mac 检查 v2 心跳，先安排 1 个已经批准的商品，再按原上架流程执行并回查可售库存。
5. 以后手动启动使用 Start-Production.cmd。

升级脚本会停止并禁用旧的 `FlowHub Acceptance Agent` 登录任务，防止旧程序占用设备锁。新生产程序的登录自启应在真实 Windows 验证通过后再配置。

## 工作方式

Mac 负责选品、店铺分配、同款去重、全部业务校验、共享 ERP 限速、日志和异常回查。
Windows 只执行 Mac 下发的指定毛子 ERP HTTPS 请求，不能自行选店、改商品或运行任意脚本。
执行时 ERP 凭证通过私有 HTTPS 传入 Windows 内存，只允许发往 api.maozierp.com；不写入本地配置。
本地仅保存已执行请求编号和待回传结果。断网或重启不能重放已执行请求。

多机仍共用同一毛子账号的限速额度，增加电脑不会绕过账号限速，也不保证吞吐量按电脑数量增长。
当前只支持明确商品的小批量路由；批量自动分配、按店类目与历史销量优化仍需后续实现。
