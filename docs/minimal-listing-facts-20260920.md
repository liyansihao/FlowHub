# 毛子 ERP 跟卖的资料补全策略

新商品使用 `maozi_follow` 时，完整商品档案补全不是主流程硬门禁。主流程只保留能够安全计算和提交的最小资料：商品标题、主图、卖家与 SKU 身份、重量、长宽高、类目、售价、采购价和审核证据。

生产数据目录的 `publication-policy.json` 支持：

```json
{
  "backend": "maozi_follow",
  "dossier_mode": "optional"
}
```

`dossier_mode=optional` 是毛子 ERP 跟卖的默认策略。它使用 compareBot 已批准的利润事实生成发布快照，不要求完整 Ozon 属性档案，也不会为跟卖任务启动完整资料补全队列。

`dossier_mode=required` 是严格模式。它保留完整资料包门禁，适合官方商品导入、FBS/FBO 需要属性的任务，以及需要重新确认完整商品档案的人工修复。

历史发布记录仍按自己的后端、offer 和日志回查，不受新策略切换影响。重量和尺寸仍必须通过邮政包裹校验，避免利润计算和物流计费使用不同的商品事实；标题、图片和来源身份仍必须通过同款审核和历史写入保护。
