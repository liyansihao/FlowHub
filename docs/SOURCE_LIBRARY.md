# 商品来源与筛选模块（2026-09-11）

## 本次实现

种子范围按用户最后一次要求：工作区这几个月已上架的商品，核对当前未归档状态后使用；有本店销量证据的优先，无销量不排除。飞书 `tblyZoXg1NDPXljf` 的明确下架要求优先于销量。

新增入口：**自动化 → 商品来源与筛选**。采集开关独立于上架工作流。模块中心提供内置候选模块 **商品来源库（初筛与待核查）**，选中后主流程从自己的库补充候选，不为每次筛选重新抓榜单。

- 历史导入读取主要 E/F 上架流水、引擎 listed 记录、FlowZ 事件和 FlowEF 已核验可售数据库；保存文件、行号或数据库行号。按工作区＋店铺＋货号去重，来源身份冲突不自动采用。
- 当前店铺商品回查只走仓库毛子 ERP 直连；来源 SKU 与本店新 SKU 分开。归档未知进入待核查，不填为未归档。
- 本店订单按订单号＋货号去重，已送达件数作为有证据的销量下限。取消订单会撤销已观察到的件数。这个数不是完整历史净销量，也不是榜单销量。
- 商品库按工作区＋来源 SKU＋来源店铺去重；保留原始榜单记录、来源查询、首次发现时间、采集时间、供应方更新时间、实时核查时间及证据哈希。
- 筛选提供统计均价区间、最大重量、类目、最低 28 天榜单销量、纯 FBS 和新鲜度。输出通过、失败和缺失原因；缺失不当作零。均价和当前售价分列。
- 持久化任务有租约、页码、重试时间、失败分类、店铺样本评估和阶段配额；同一来源店铺只加入一次评估队列，评估使用本地样本，共享类目采集任务，避免为不同卖家反复抓同一类目。
- 来源待核查任务也计入 30 个下游积压上限。分页结果和检查点同一事务提交。接口悄悄把每页 100 条截为 50 条时，不按请求大小提前结束。
- 单个候选可实时核查、查看证据、导出协议 JSON，或送到主软件的“需要处理”列表；自动候选模块同样将缺少售价与规格的候选放入待核查阶段。

## 使用

1. 重启使用本目录源码的 FlowHub API 和 worker，使新增代码生效。桌面发行包未在本次重新打包。
2. 管理员进入“商品来源与筛选”，导入本地历史上架记录。范围不限于 8 月；只导入可识别的历史证据。
3. 配置该工作区的毛子 ERP 连接，保存筛选条件并启用采集。需要已配置的工作区飞书只读连接供下架清单核对。
4. 在工作流配置中将候选模块改为“商品来源库（初筛与待核查）”，或者从来源页单独送入待核查列表。

历史导入不是当前状态核验；全部店铺回查完成前，不能把历史绑定总数当作当前可用种子数量。正式工作区未在本次自动更换候选模块或启用采集，真实验收使用单独数据库。

## 接口与文件

2026-09-11 核心扩展实测：5 个未归档已签收销量种子解析到 4 个来源店铺，但榜单 `seller_id` 过滤未生效，有限类目补查也没有发现目标店铺新增商品，完整店铺扩展验收未通过。详见 [验收报告](../reports/source-expansion-core-20260911/验收报告.md)。历史导入已补充具有明确来源及上架记录关联的 `outputs/profit-selection-*/order-review.json`，拒绝 URL 身份不一致或缺少关联证据；模块回归 15 项通过。

- `GET /api/sources`：按已保存规则查询；游标与状态过滤。
- `PUT /api/sources/settings`：筛选、独立采集开关及加密连接。
- `POST /api/sources/import-history`：管理员导入。
- `GET /api/sources/seeds`：当前种子与证据。
- `POST /api/sources/cycle`：执行一个有容量限制的任务周期。
- `POST /api/sources/{sku}/recheck?seller=…`：实时物流资料核查。
- `POST /api/sources/{sku}/handoff?seller=…`：幂等送到主软件待核查。
- `GET /api/sources/export`：`flowhub-source-candidates-v1` 协议导出。

存储、判断逻辑在 `source_library.py`；历史导入在 `source_history.py`；采集适配在 `source_acquisition.py` 与 `bridges/source-library.mjs`；下架清单复用在 `source_delists.py`；API 在 `source_api.py`。新渠道应输出统一商品与证据格式后调用 `SourceLibrary.put`，不能伪造当前售价、规格或核验时间。

## 2026-09-11 一小时同店扩散验收

不限专区，纯 FBS、重量 ≤ 2kg、统计均价 ≥ 100 RUB、榜单销量 ≥ 1、明确可跟卖，排除历史商品和明确下架清单。共用 60 分钟预算，实际采集 56.12 分钟，176 个当前未归档种子绑定解析出 153 个来源卖家；新增 65 个同店初筛候选，65 次实时核查尝试中 38 个物流通过，来自 3 家店铺。候选与核查结果在第 52.14 分钟已经保存。采购同款和利润未验证。

新增 `seller_scan` 队列和 `same_seller_only` 条件，以精确卖家 ID 和根种子证据判断同店来源。解析新种子时会关联同卖家已采集商品，每次最多 500 条，保留原市场采集时间及证据链；普通刷新不会丢失同店证据。数据过期、根种子归档或明确下架时停止相应的新扫描。此能力限于可读取的榜单覆盖，不能当作全店商品遍历。

本轮有效顺序是扩大跨店铺种子、关联已有库，再补页和实时核查；不是等样本随机对照，不能外推持续每小时产量。详见 [一小时验收报告](../reports/seller-expansion-hour-20260911/验收报告.md) 和 [候选清单](../reports/seller-expansion-hour-20260911/同店候选.csv)。源码已修改，未重新打包桌面发行版或开启生产采集。
