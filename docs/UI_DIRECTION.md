## 正式运行数据接入（2026-09-10）
管理员自己的运行概览和商品页优先显示同目录 FlowEF-production 正式发布记录；接口以只读 SQLite 连接读取，按白名单返回图片、相似度、利润和状态，不返回日志、原始证据或凭据。其他用户和管理员查看其他工作区时仍隔离。页面明确显示来源、读取时间、过期心跳状态，正式流程监控页不触发 FlowHub 写入开关。每10秒轮询，搜索框保持焦点也可更新；图片详情展开时暂缓刷新，关闭后恢复。统计仅含进入正式发布的任务，不等于全部候选池。19项测试通过，并用隔离只读页面验证正式记录显示与搜索保留。
