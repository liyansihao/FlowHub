用户提供的视觉参考：https://design.hazel66.top/ 。参考其暖白底色、杏色强调、分组侧栏、轻边框和紧凑工作台布局；保留FlowHub品牌与实际已有功能。

界面统一覆盖登录、概览、商品、工作流、店铺、模块、用户、禁止清单和管理员事件。商品表直接显示候选图与1688图，图片对照抽屉加宽；相似度显示为0–100评分，避免误读为正确率。状态筛选继续通过原API查询，支持在当前最近100件中搜索标题、源SKU和任务编号，按更新时间排序。

## 正式运行数据接入（2026-09-10）
管理员自己的运行概览和商品页优先显示同目录 FlowEF-production 正式发布记录；接口以只读 SQLite 连接读取，按白名单返回图片、相似度、利润和状态，不返回日志、原始证据或凭据。其他用户和管理员查看其他工作区时仍隔离。页面明确显示来源、读取时间、过期心跳状态，正式流程监控页不触发 FlowHub 写入开关。每10秒轮询，搜索框保持焦点也可更新；图片详情展开时暂缓刷新，关闭后恢复。统计仅含进入正式发布的任务，不等于全部候选池。19项测试通过，并用隔离只读页面验证正式记录显示与搜索保留。

## 正式商品管理（2026-09-10）
正式商品详情增加继续上架、下架、归档、库存、CNY价格、操作回查按钮；确认区域显示店铺、源SKU和具体目标。仅管理员自己的本机正式工作区可用，使用已有FlowEF Seller身份和毛子ERP归档接口。后台拒绝仍在自动处理中、未知或封禁店铺的商品。继续上架仅激活原产品，不新增导入；正库存与改价检查实时飞书下架清单、隔离记录和业务反馈。归档先回查所有已查询仓库库存为0，再精确匹配ERP店铺/offer/SKU提交，最终Seller归档状态回查。调价后旧利润隐藏，避免误认为已重算。

操作意图在写入前存入 production/management 私密目录；接口超时保留待回查，同一请求不会重发写入；新请求在旧结果未明时被拒绝。全局操作锁避免网页操作并发。管理结果覆盖显示状态而不改写自动流程原始计划。用户在页面确认后才执行；本次测试没有修改任何真实商品。自动测试覆盖权限、CSRF、输入验证、未确认库存请求禁止重放；隔离只读页面验证按钮与改价确认表单。

目前这些按钮接入的是本机正式流程商品，通用用户插件商品尚未接入此管理接口。平台实写验收需对用户选定商品实际操作后确认。
