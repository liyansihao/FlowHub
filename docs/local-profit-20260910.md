# 邮政 / GUOO 本地利润计算 · 2026-09-10

网页地址 http://127.0.0.1:38427/ ，登录后进入「利润计算器」。

本次新增本地无网络计算模块，未替换正在运行的 FlowEF 正式利润审核，也未启动第二个发布器。计算器本身不需要毛子 ERP；当前生产流程的其他阶段仍依赖毛子 ERP。

## 输入、范围与公式

- 所有成本和利润使用人民币，商品货值 = 预计成交人民币价格 × 明确填写的 RUB/CNY 结算汇率。重量为包装后克重，尺寸为厘米。
- 邮政只涵盖附件的 Extra Small：1–500 g，1–1500 RUB；不把此档外推到大件。没有从原表臆造尺寸/禁限运条件。
- GUOO 俄罗斯 Ozon realFBS 15 行、FBP 12 行，PUDO/Courier 同行同价合并展示。未涵盖同书中 Yandex 和其他国家专线。
- GUOO 按文字标注范围（含端点）确定档位，重量向上取整到克，排序尺寸以最长边匹配长。价格处在 1500–1501 或 7000–7001 之间不自动填补原表空档。
- 大件取实重与体积 cm³ / 12000 的较大值。原表 F5/G5 在货值端点漏用材积重、FBP 一处尺寸判断与路由文字冲突；本实现保守地对所有合格大件应用材积重。与表格错误结果有差异，界面说明。
- 总成本包含采购、国内运费、包装贴单、国际运费、佣金、收单、另计尾程、提现、广告、损耗预留和其他费用。成本利润率 = 利润 / 总成本 × 100；净利率 = 利润 / 售价 × 100。门槛严格大于，使用未显示舍入前的金额判断。显示四舍五入到分，各显示分项相加可能有 0.01 元舍入差。
- GUOO 表仅报价运费，收单/另计尾程/提现必须显式输入（已含费用可填 0），不自动套邮政收费。仓储、增值服务、税费等需要纳入包装、其他或损耗费用。
- 利润测算不代表可承运；原表禁限运、电池条件和店铺实际开通路线仍需核实。界面不能执行发布或切物流。

## 邮政公式审计

原 XLS 的 BIFF 公式经 xlrd 反编译：

```
C9 = C7+K7*G7
G9 = C13*1.9%
K9 = IF(C13*0.02<1.3,1.3,IF(C13*0.02>18.0,18.0,C13*0.02))
G11 = C13*C11
K11 = (C13-G11-C9-G9-K9)*1.2%
C17 = C13-C3-G3-K3-C9-FO9-K9-G11-K11
```

C17 错引空白 FO9，漏扣 G9。原样例售价 100，采购 10，重量 0.1 kg，佣金 15%，正确利润 65.6808 元，原缓存 67.5808 元。15% 仅为样例，不能作为通用类目费率。提现结算余额为负时取零，避免产生负手续费抵扣。

## 模块接口

内置模块 `local-profit-chinapost` / `local-profit-guoo`（driver `local-profit`）。运行时无第三方网络调用，源码 `flowhub/local_profit.py`，费率 `flowhub/tariffs/shipping.json`。原始附件私密备份 `data/tariff_sources/`，不对网页开放、不纳入 Git/Windows 包；JSON 保留来源文件名、SHA256、单元格。

候选模块须在每件商品 `candidate.origin.profit_inputs` 输出 ProfitInput 对应字段，包含明确 `route_id`、`eligibility_confirmed: true`、具体类目、佣金及来源、结算汇率和所有附加费。金额/重量/尺寸以当前 candidate、match 中规范字段为准，防止复制的旧报价覆盖新商品事实。

独立 UI 请求 `POST /api/profit/calculate`，需登录及 CSRF。目录 `GET /api/profit/catalog`。所有用户可使用计算器，没有凭据输入或外传。普通用户不可注册任意内置 driver。

当前候选适配器未自动补齐新模块输入，不要仅在工作流切换模块就期待自动生产；缺数据会进入现有异常处理，而不是猜测费用放行。现有 FlowB matcher 仍可能调用 ERP 利润计算，这次新增模块不等于完成整个链路脱离 ERP。
