# 收藏恢复与回查调度修复（2026-09-15）

范围：仅收藏可见性恢复、收藏超时分流、无效回查调度。

## 已验证的问题

- 收藏等待原来没有退避；准备发布阶段收藏消失时也会原地重复检查。
- 收藏超时被错误送去查店铺在线商品，尽管尚未发起导入。
- 原卡单 5432189063 使用原请求体再次收藏后，接口返回 code=1 / 收藏成功，立即查询得到记录 24364754；几分钟后全量与精确查询均不再返回该收藏，且无导入记录。远端移除原因未得到确认，不能把接口成功当作持久落库。

## 实现

- 首次收藏保存确认时间与次数；成功后在同一操作内回查，确认可见后继续原有发布前检查和幂等导入流程。
- 只对已确认成功且再次查不到的收藏进行有限恢复：首次加两次重试，至少间隔 120 秒；重试前保留原审批、下架排除、身份与已导入检查。
- 未知写入结果仅回查；收藏恢复不重置原货号、不重放导入请求。
- 收藏超时按收藏阶段恢复；准备发布时收藏消失也退回此流程。
- 收藏轮询 60/120/240/480/600 秒退避；真实导入、库存回查优先。恢复后重新进入发布队列。
- 保留共享 API 限速，不改选品、价格、利润、来源采集或其他业务规则。
