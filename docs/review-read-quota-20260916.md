# 审核网站读取额度故障（2026-09-16）

现场：静态首页 HTTP 200，/api/reviews 返回 HTTP 500 / 1101。
Cloudflare tail 确认异常：Exceeded allowed rows read in Durable Objects free tier.
异常出现在 ReviewStore 构造阶段；当日存储读取额度已耗尽，部署不能恢复额度。

修复：ReviewStore 在对象首次访问时读取持久存储，后续轮询使用对象内缓存；写入先持久化再更新缓存，事务失败清空缓存，重启从数据库恢复。审核队列仍只显示 needs_review。外层捕获存储异常，返回可读的 503 提示。

17 项测试通过，包含连续 100 次读取不增加 SQL SELECT、重启恢复、事务回滚后缓存恢复，以及审核权限/队列回归。
部署版本：e4b6f89d-cae5-4e22-9051-5c91593f39ca。

免费额度每日 UTC 00:00（北京时间 08:00）重置。升级计费方案需用户决定；未执行购买或迁移，未清除原数据库和审核指令。修复收益目前仅有本地测试证据，线上读写须待额度恢复后核验。
