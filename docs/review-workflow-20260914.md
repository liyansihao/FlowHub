# 审核流程与毛子资料实测（2026-09-14）

## 已部署行为

审核台按人工同款复核、缺资料、测算过期、发布异常分类。显示最新来源库缺项、最近毛子补采失败原因，并提供补资料 / 刷新测算。已提交或已有发布计划的商品保持原发布回查流程，不允许从审核台重建发布。

人工修复持久保存 `repair_full_dossier`，补完整档案，不因已有估值输入而跳过属性。旧报告保留用于精确核对；补齐后，图片、身份、包装、售价等关键数据不变且原审核在6小时内，可保留原同款结果。原人工待审仍回人工待审，只有原已批准报告才沿用原发布路径。过期或关键数据变化必须重新测算，不刷新旧批准时间。

收藏查询覆盖已导入和未导入两组并完整分页，已导入收藏恢复原草稿；未知写入结果不重发。历史真实参考价只用于创建采集元数据，不变成新售价证据。

云端决定基于实时快照与修订号，修复旧版 POST 只认部署种子的问题。快照、决定与确认分开存储；本地事务验证租户、修订、业务门槛、租约及重复操作。旧版种子仅供展示。
