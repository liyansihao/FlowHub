# 在售商品同款筛查与历史销量分流

用户授权本轮全部可售商品：不同款且本店历史无销量直接下架；有过销量保留待审核。订单采用毛子ERP不限定日期的完整分页，按店铺+货号、店铺+SKU匹配未取消订单购买件数，包含待发货，查询不完整不视为零销量。飞书明确下架清单优先。

实现独立 `sellable_audit_cards` 台账，避免把来源选品SKU当成本店SKU操作。全量识别脚本继续写本轮报告；`scripts/apply_sellable_audit_policy.py` 读取本轮不同款结果、绑定当前商品图片标题、核对历史订单并分流，待审核卡片经原增量同步进入 Vercel。审核台保留决定与版本校验；确认同款仅保留现有在售商品，确认不同款/下架请求进入精确商品下架流程。

下架只走共享节流的原生毛子接口，先核对店铺、货号、SKU、商品ID及当前图片标题，清零全部已知可售仓库，再回查零库存、归档并回查。库存操作前持久保存原仓库存。归档响应不确定时不重新发送，继续回查。技术失败或证据变化保留阻塞状态。

核验发现一条 Qwen 理由与规则矛盾：一侧无品牌及包装数量不同被称为明确品牌冲突。现在该类结果进入人工核对。公司6号SKU 5814417928 曾被自动清零，归档前被拦截；根据原发布台账的指定仓库实测99库存，核对飞书禁售清单后恢复嘉兴邮政仓99，并真实回查selling，未归档。完整恢复证据在 `reports/sellable-identity-20260916/conflict-restoration.json`。网站已核验该商品出现在待审核。

验证：6项新规则/精确身份/仓库清零/归档回查/销量聚合/品牌证据矛盾测试；43项原有审核与同步回归通过。生产全量仍在运行，不能把规则接入视为全部筛查或下架已经完成。
