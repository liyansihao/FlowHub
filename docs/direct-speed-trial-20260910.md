# 官方直发实测与速度结论（2026-09-10）

结论：真实直发已跑通，丽丽一号两件商品均经官方接口确认可售、库存 99。但本轮没有证明整体上架时速提升，不能据此全量替换正式 ERP 发布。

## 实测范围与结果

- 使用现有 Worker 和真实店铺；工作流整体仍暂停，仅对持有独占任务租约的指定新候选逐步执行。后台 worker 负责恢复已提交任务。

## 发现与处理

1. **英文标题审核拒绝（已修复）**：原草稿的可编辑标题为英文采集标签，属性 4180 实际保留俄文原题。映射现优先使用原俄文标题；无原俄文标题时仅用已核实的官方俄文类型与来源纸张格式/数量构造基础标题，不能生成则预检拦截。第一件使用同一 offer/product 修正标题，没有另建卡。修正提交至可售核验 115.94 秒。
2. **库存未确认恢复（尚未证明自动恢复稳定）**：第二件审核通过后首次库存操作抛出异常，后台持续只读回查仍为无库存。本次核对原商品、批准状态、原仓库、目标库存与实时下架保护后，受控补写原商品库存 99，得到官方 `updated=true`，再回查可售。第一笔异常的原响应没有被保留，不能断言具体平台拒绝原因。
3. **已补库存收据**：官方直发以后每笔库存写入保存加密意图、原响应或未知异常类型，便于区分确定拒绝与未知结果；不会因此自动重放未知写入。仍需要基于真实响应完善自动恢复并再次做正常路径测速。
4. **合格候选供给不足**：本轮仅 2/26 进入发布。更换发布模块不会解决同款/利润筛选耗时与低通过率。
