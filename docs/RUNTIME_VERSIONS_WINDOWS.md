# Windows 版本上报更新

用于已注册、已安装 Full Agent v3 的电脑。本包仅更新版本上报所需的四个 Python 文件，不安装模型、依赖，也不修改账号、任务账本或未返回结果。

## 使用

1. 主控管理员暂停向待更新设备分配新任务，等待在途任务结束。未知 ERP 结果留给主控回查，不能删除账本或强行重放。
2. 正常关闭当前 Full Agent 窗口，确认 ERP 与计算子进程退出。
3. 解压本包，双击 `Upgrade-Versions.cmd`。它使用原有 compute-venv，校验安装文件基线并获取两个独占锁；仍有执行端运行时拒绝更新。
4. 更新成功后脚本启动原设备 Full Agent，继续使用原注册信息。约 30—90 秒内主控应读到 erp-agent、full-agent 和 compute-worker 三类版本。计算模型加载时间可能更长。

若提示 installed code differs，保留输出并让管理员核对该机器安装内容，不要强行覆盖。本包不会关闭进程或抢占运行锁。

## 证据边界

上报的是各进程启动时观察到的源码和 Python 依赖指纹。进程运行期间修改文件，不会改变该进程原有报告。模型名称与 revision 来自成功初始化的 ranker，但没有声称完成模型权重全文件验真。旧客户端没有报告时，主控会明确显示 unknown/缺失，不能以当前安装包版本代替它。

协议和上架行为保持兼容；版本接口不可执行命令、更新代码或读取凭据。
