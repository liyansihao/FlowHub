# 运营与审核双入口（2026-09-22）

用户授权：本机退款、零库存增加“已经处理”，并部署至现有 Vercel 审核站，将运营与审核做成两个工作区。

- 本机运营仍为 http://127.0.0.1:8768/；退款与零库存支持标记、撤销、处理状态筛选。
- https://flowhub-review.vercel.app/ 保留原审核；/operations/ 是运营。首次从本机左侧“云端运营”入口授权浏览器。访问凭证与审核同步凭证分离，服务端通过 HMAC 派生；浏览器只取得运营权限，不取得店铺密钥或审核同步权限。
- 云端仅同步退款/售后和未归档零库存，不上传买家消息或店铺 API 密钥。买家消息仍在本机工作台处理。
- 云端处理记录为权威状态；本机约每分钟拉取标记，写入先由云端确认。网络失败不显示为处理成功。记录有版本校验，隔离不同店铺、履约类型与记录 ID，并保存操作时间与审计历史。
- 平台售后状态与内部“已经处理”独立。标记不会退款、改库存、上下架或发送消息。零库存解除后再次出现会重新进入待处理。
- 平台读取周期保留：售后约 10 分钟，库存约 15 分钟；云端扫描周期 60 秒，仅变化时上传，未变化最多每 5 分钟刷新镜像时间。本机离线保留旧快照并显示时间/延迟。
