# FBO / FBS 来源准入规则

用户授权：main 和远端均允许 FBO、FBS 商品上架。这里指来源商品配送模式；目标店铺仓库、库存和物流计价方式不变。

改动范围：取消采集和候选入口的纯 FBS 限制，兼容已有 pure_fbs 配置；发布检查接受 FBO、FBS 和混合模式。未知模式仍遵循已有显式授权路径，卖家禁止跟卖、身份、时效、同款、价格和利润校验保留。

估价桥接使用仓库内的来源规则副本，避免共享 ozon-runtime 的旧纯 FBS 规则继续拦截 FBO。外部依赖源码与运行中的生产目录未修改。历史人工决定、未决发布和数据库未迁移。

验证：隔离临时数据库及模拟接口；覆盖来源筛选、估价 Node 桥接、发布准入、FBO/FBS 混合来源、禁止跟卖及过期证据。同步仅涉及 Git main，不部署或重启生产，不触发真实上架。
