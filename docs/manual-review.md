# 人工审核

入口：左侧“上架工作 → 人工审核”，或工作区 Web 实例的 `/#reviews`。此页读取当前实例的 plugin_pipeline 待审核队列；不同桌面实例的数据仍然隔离。

每页20件，可按SKU搜索。卡片展示 Ozon 与1688图片及商品链接、采购成本、拟售价、成本利润率、DINO相似度、千问判断和理由、测算时间。点击图片可查看原图。没有有效同款复核或测算证据时，“通过”不可点击，并显示阻塞原因。

操作均需填写理由：
- 通过并继续上架：人工确认当前商品与当前货源的同款关系，进入原发布队列。保留原机器判断及测算时间，不延长价格有效期；利润、明确冲突、来源限制、禁售、库存和目标仓库检查继续执行。通过不等于平台已经上架成功。
- 拒绝该候选：终止此SKU/卖家的当前候选流程，保留审核快照。
- 退回补资料：进入现有资料补齐队列，清除旧测算缓存以重新测算。旧报告完整保存在审核日志里。

页面右上方“审核记录”显示最近50次操作及审核人、时间、理由。提交绑定所见报告版本；重复点击、队列被其他执行器改变、活动租约或已提交平台的记录不能重复处理。接口沿用工作区权限和CSRF校验。

验收：42项相关后端测试通过；隔离浏览器实际完成登录、必填理由、三种操作及3条审核日志，并检查图片加载和无JavaScript错误。当前真实工作区仅做读取验证，未代用户点击通过。
