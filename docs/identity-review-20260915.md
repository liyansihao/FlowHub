# 2026-09-15 同款审核与售价口径

用户确认：只要有售价即可补资料，优先最低跟卖价，其次普通售价；审核台只判断有无同款。

- `evaluation_requirements.review_sale_price` 为审核专用价格选择器。接受带真实采集时间的历史普通标价，不将月均销售价或采购成本当作普通售价。保留币种、原始时间、来源、历史标记；不会把补入时间冒充采价时间。
- `identity_review` 单独读取图像、标题、规格。与原绑定一致的识别证据可以复用；规格变化时复用相同图片的 DINO 排序、重新做 Qwen 审核。价格、毛利、重量完整性、资料时效不参与同款结论。
- `plugin_pipeline.body.same_product_only=true` 使用独立同款审核。审核台“重新识别同款”进入 queued，调用该通道。新进入人工审核且无发布记录的商品也标记这个范围。
- “确认同款”记录 `identity_review` 和 human_reviews 审计，队列进入 `same_product_confirmed`，不会进入 publishing。品牌或型号冲突、过期页面版本、商品对比资料变化、活动租约均不能被旧页面覆盖。
- 不同款结论仍记录为 rejected。模型与图像分数分歧保留同款复核。1688 未返回候选为 no_candidates，不能记成已确认不同款。
- 审核台不再展示上架异常记录；已发布记录继续由原发布流程回查。后台原有售价时效和上架资格校验保持独立。
- Netlify 快照带受信本机产生的 local_history，只用于展示审计，不进入远程命令队列。
