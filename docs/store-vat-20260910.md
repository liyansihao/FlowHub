# 按现有 ERP 上架结果配置 VAT

用户要求：毛子 ERP 怎么填，新模块就怎么填。

从正式生产 journal 精确选取丽丽一号、四号各 3 件 `stock_verified` 商品，使用各自 Client ID 的官方 `/v5/product/info/prices` 回查。6 件均返回 CNY、`price.vat = 0`。因此这两家账户的本地发布配置设为字符串 `"0"`，不推断其他店铺或一般税务义务。

账户配置保存在私密运行文件 `data/store-vat.json`，包含账户 ID、值、来源、核验时间与样本 offer_id。已连接的一号店同时更新店铺配置。四号的账户配置在接入该账户时生效；不改变仍由 ERP 执行的正式发布。

直发模块按 Client ID 精确取配置，覆盖候选来源自带的税率。未核验账户不套用；冻结后配置变化会阻止沿用旧发布资料，需要重新准备。

验证：一号店 3 件历史来源样本（5023023671、1880184583、5203001553）完整 prepare 均返回 `ready=true`、无缺项。本次无 Ozon 创建或库存写入。18 项直发/采集测试通过，包括账户隔离、覆盖原卖家税率、配置变更导致冻结计划失效。

回查证据：`reports/store-vat-readback-20260910.json`；资料预检：`reports/source-detail-acceptance-20260910.json`。两者为本地运行报告，不随源码提交。
