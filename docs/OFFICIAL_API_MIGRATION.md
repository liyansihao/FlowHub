# 官方 Seller API 发布迁移

## 问题与验收目标

毛子收藏、导入、同步、库存回查共享请求容量，认证异常和旧回查积压会影响新发布。本分支将完整本地资料的创建、初始定价、库存写入与可售回查接入官方 Seller API，同时保持原有授权、来源去重、身份、利润审核和明确下架排除。

验收：合成完整商品通过官方接口提交并确认库存/可售；响应丢失和重启不重发；凭证异常只冷却对应凭证；旧毛子记录不重新导入；下架必须验证零库存及归档；批量查询不混入别的商品。

## 路由与兼容

店铺 `config.publication_backend` 可为：

- `official_preferred`（默认）：新商品具备完整本地资料时用官方发布；本地资料不足时保留原毛子流程。
- `official_only`：新商品缺资料或凭证时明确阻断并显示缺项，不通过毛子补资料或创建。
- `maozi`：新商品继续毛子创建。

发布记录一旦存在，以记录中的 backend 为准。没有 backend 的旧记录视为毛子记录；不得批量补成 official。修改配置不能转移已经提交的发布意图。

官方模块只读本地资料和已完成的精确账号/SKU快照，可利用官方属性接口映射已有资料，不启动 SourceCollector.collect。税率、俄文标题、图片、必填属性及来源必须齐全；包装必须匹配批准的利润输入。初始价格随导入提交，本次没有新增独立的批量改价业务入口。

**仍保留首次正式提交前的毛子去重检查。** 导入日志和收藏导入标志的缺失不能由本地数据库的缺失替代；核验成功只缓存15秒，确认已导入则持续阻断。官方提交完成后的回查和库存不再调用该检查。完全摆脱首次去重依赖，需要另行建立并核验覆盖其他发布工具/人工导入的统一来源登记。

`official_observations` 默认 true：有官方凭证的旧毛子任务改用官方商品/库存回查和店铺额度。`official_inventory` 默认 true：这些任务的库存写入也走官方，保留原 journal 和 stock_guard。显式设为 false 可保留旧行为。没有官方凭证的旧流程保持原通道；官方接口失败不静默退回毛子。

旧任务仍可能调用毛子检查目标、来源和修复图片。官方 product_id 不等于毛子 record_id；图片修复前重新从毛子精确定位并比较 shop、offer、product、SKU。

## 请求与失败处理

- 调度状态按凭证指纹及接口持久化，与毛子队列分离。默认间隔0.25秒只是保守起点，不代表已验证的官方配额或承诺速度。
- 401/403 冷却对应凭证300秒；429遵守 Retry-After；网络/5xx延后对应接口。更换凭证形成独立作用域。
- 类目和属性字典缓存6小时，内容加密保存；商品/库存状态不缓存。
- 同一进程同一账号的并发商品查询在10毫秒窗口合并，最多100个offer。每个调用者只得到自己请求的结果；重复/陌生offer使整批失败。按店铺互斥会限制实际合并机会，不能把批量上限当成已获得的提速倍数。
- 写请求不自动重试。超时/5xx保留意图，只回查；仅确定没有发送/明确拒绝的情况恢复可重试状态。
- 原有阶段退避、正常回查与历史回查调度继续生效。

新增官方商品的下架和恢复沿用网站显式操作。下架读取完整库存分页，清零所有返回的库存仓库，再归档并回查；缺库存证据不算成功。恢复检查有效审批、原商品与仓库绑定、来源变化和飞书排除，不重新创建商品。保留待确认写入，不盲目重发。

## 部署与回退

本分支在独立工作树开发，未复制生产 data、密钥和账号配置，也未重启生产进程。分支包含单独的既有未提交源码基线，便于与本次改造区分。

上线前用已有账号配置验证官方 Client-Id 与仓库绑定、类目资料覆盖率以及接口当前合同。在一组明确选定的新任务上小批切换，观察首次确认可售量、接口错误和ERP调用次数，再扩大。测试通过不代表真实生产吞吐提升。

回退新任务可设 `publication_backend=maozi`；**已有 official 记录仍须用支持本分支的程序回查**，不能直接回退到不认识 official 记录的老程序。不要清除意图、来源占用或写入记录。关闭 `official_observations`/`official_inventory` 不会改写已固定的 official 发布记录。

只读观测命令：

```sh
python scripts/report_official_api.py --data /path/to/flowhub/data
```

报告区分累计HTTP请求、缓存命中、平均网络耗时、当前认证/限流冷却、各通道发布阶段，以及最近15分钟首次确认的官方可售商品数。计数不等于独立订单或持续吞吐保证。
