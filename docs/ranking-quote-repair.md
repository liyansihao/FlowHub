# 榜单商品实际售价补充

基于唯一生产 a777fe0 的最小修复。仅在现有补资料阶段处理：有有效榜单销量凭证、缺少测算价格且不要求完整发布资料的商品。种子扩展、榜单轮转、匹配、利润、500g、库存99、店铺轮转、发布后端和 Offer 身份均不变。

原补价接口 sku3 的真实返回没有 sellerId/avgPrice，无法补齐 96 个榜单候选。新分支通过已有来源浏览器配置，只读打开对应 Ozon 商品页；解析主商品 SKU、当前卖家组件中的明确卖家 ID、价格组件绑定的 SKU 和普通 price。仅接受可售、身份一致、明确 RUB/CNY 币种、有效时间的报价；不接受会员价、划线价、统计均价或其他卖家报价。价格写入现有 proposed_sale_price，并保存实际观察时间、页面 URL、内容摘要和原始价格文本。榜单证据与原 collected_at 不刷新。

新浏览器读取使用独立 ranking-quote-browser-profile 和 ranking-quote.lock，一次仅允许一个取价浏览器。原 source-loop.lock 还覆盖 ERP 核验与数据库同步，生产小批验证发现共用它会使取价持续等待，因此不争用原来源采集配置。取价锁忙、网络错误沿原补资料依赖等待机制重试；身份错误、下架或缺少价格仍进入原人工处理，不放宽原判断。取消与超时先退出浏览器子进程再释放锁。

改动范围：新增 ranking_quote.py 和只读 ranking-quote.mjs；repair_facts.py 增加榜单取价分支；repair_retry.py 识别该分支的临时依赖错误。另提供一次性恢复脚本和测试，不引入新队列或后台循环。

`scripts/recover_ranking_quotes.py` 默认只读计划，必须提供明确 SKU 清单。只恢复原机器生成的 direct_valuation_facts_unavailable、facts/valuation 阶段、仍有效榜单来源的未审核任务。存在人工审核、上架控制、发布记录、任务、下架禁止或有效租约的商品均保留。应用时先归档原队列及工作流，保留原准入身份，不重建任务、不重复发布。

实测取价：2026-10-08，SKU 3027500170、卖家3471788，350 RUB；SKU 2013720657、卖家2505349，150 RUB。测试夹具来自真实页面的必要字段，已去除跟踪信息。此读取验证不等同于利润合格或上架成功；生产验收单独记录。
