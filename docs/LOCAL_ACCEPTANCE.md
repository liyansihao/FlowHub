# 本地验收与交接

验收入口：http://127.0.0.1:38427/ 。账号 `admin`，初始随机密码在本机 `data/INITIAL_ADMIN.txt`，首次登录自行改密。该文件只用于本机交付，禁止打入安装包。

## 可操作验收

1. 管理员登录后，运行概览展示自己的真实任务；商品页面点击商品可比较原商品与1688图片、分数和利润。
2. 工作流配置中可以替换四类模块，配置利润、物流、库存、候选总量和真实提交上限。提交后任务固定当时规则，不修改已在途任务。
3. 店铺连接中填写用户自己的ERP Token、Seller Client ID/API Key、毛子店铺ID、仓库与水印，验证成功再参与轮转。
4. 模块中心由管理员注册HTTPS适配服务或预安装插件；普通用户选择模块并填写自己的密钥。
5. 用户管理中创建普通用户。该用户首次改密后只能看到自己的店铺、商品和工作流，不能读取管理员事件或其他用户数据。
6. 暂停停止新任务，已提交的商品仍在原店回查。未确认写入不会切店重试。

## 真实首批

仅丽丽一号、最多3件。沿用图片70/55、邮政成本利润率严格大于30%、库存99，写入前核对飞书明确下架清单、历史禁止清单和源SKU占用。只有Ozon返回真实商品SKU、可售状态和指定仓99库存才算完成。

旧FlowEF发布器在新系统首批期间暂停，避免并行写入；新系统的SKU写入共享占用记录，旧系统恢复后不得重复发布这些SKU。恢复旧系统前必须确认新系统暂停新增，所有已绑定店铺的任务均完成并独立回查，无未确认写入。

当前证据保存在本机 `data/live-acceptance.json`。接口accepted、收藏成功、已创建商品和历史旧系统商品均不冒充本次验收成功。

## 稳定性证据

自动测试覆盖多用户隔离、密钥加密、登录与CSRF、真实/模拟模块隔离、游标分页不丢候选、版本固定、额度轮转、禁止清单、写入成功但响应丢失时的重启恢复、原生API身份和库存精确核验。

2026-09-10在尚未分配真实写入时，对候选worker执行SIGKILL故障注入；守护进程自动生成新worker，任务数据库保留、心跳恢复。这个短时恢复测试不等于24小时通过。

只读验收观察器每60秒独立回查首批商品；每30秒记录worker心跳。实际跨度满86400秒、最大采样间隔不超过120秒且首批商品仍全部通过，才标记24h_verified。电脑关机或强制休眠不计正常运行。

## 运维

```sh
.venv/bin/python -m flowhub.control status
.venv/bin/python -m flowhub.control stop
.venv/bin/python -m flowhub.control start
.venv/bin/pytest -q
```

不要直接删除数据库租约或把publishing/stock_pending改成未提交。未知结果只能在原店按固定offer_id回查。需要恢复备份时，数据库与master.key必须成套恢复；未经官方查询不得重新创建已有商品。

HTTP接口不暴露源代码、密钥、原始日志；服务器所有者仍能访问部署文件。当前为本地验收版，正式多人公网部署还需TLS、服务器备份、权限与负载验收。当前FlowB模块仍依赖本机旧工作区；独立服务器需迁移该兼容模块的运行依赖，或接入新模块。
