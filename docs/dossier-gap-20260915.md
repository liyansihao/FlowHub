# 毛子资料缺口核查与修复

## 证据

- 毛子category-by-sku返回精确来源SKU的重量与尺寸，不提供完整发布属性。
- 完整属性由favorite/edit_import生成的collect/detail提供。检查本地1647份ready草稿快照，均存在common_attributes；没有发现本批次因为属性只在variant中而漏读的证据。
- 清理后的110次补资料执行中，16次结果after=[]；同期9条商品首次回查stock_verified且verified=true。统计仅说明链路已在工作，不表示由本次小改动独立产生。
- 完整读取毛子采集箱610/610条记录，之前隔离的27条缺属性任务都没有对应来源草稿。其本地采集状态为17条favorite_started、10条draft_started，均没有本地plugin_publications记录。未将历史不确定写入视为未发送，也未重置这些任务的创建标记。

## 修复

repair.missing_fields原来以6小时统一判断静态资料过期，与publication.reviewed_snapshot允许7天复用的规则不一致。现在超过6小时会调用同一个reviewed_snapshot判断：来源SKU一致、字段完整、来源证据与时间有效的静态资料不再被错误要求重采。

原始字段时间不变。报价/审批仍按自己的时效判断；空属性、超过7天、SKU或字段证据不符仍算缺资料。没有修改售价、平台强制属性或重放不确定的收藏/草稿写入。

验证：88项相关测试通过；已用reload_pipeline排空并重启工作进程。

## 仍存在的边界

缺失的27份旧草稿无法从当前毛子采集箱读取，保留为待处理。21条旧价审过期问题不因复用静态资料而自动解决；获取不到有效售价时不伪造更新时间。新任务继续通过毛子直连补全及上架。
