# FlowHub · 本地验收版

网页登录的模块化上架工作台。管理员管理用户与模块；各用户有独立店铺、密钥、规则、商品与禁止上架清单。

本地入口：http://127.0.0.1:38427/ 。管理员初始账号 `admin`，随机临时密码保存在 `data/INITIAL_ADMIN.txt`（600权限），首次登录必须修改。不要把data目录发给使用者或放入Git。

## 启动

```sh
python3.12 -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/python -m flowhub.control start
.venv/bin/python -m flowhub.control status
.venv/bin/python -m flowhub.control stop
```

本机服务绑定127.0.0.1，Web/API与worker独立进程，守护进程监测退出并重启。Mac使用caffeinate防止空闲睡眠；电脑关机、系统更新或强制休眠不能保证服务继续执行。

## 功能

- 管理员创建用户、停用账号；首次改密、12小时会话、CSRF、登录限速。停用撤销会话。
- 管理员可以切换工作区，用户只能访问自己的工作区。
- 店铺连接、身份核验、仓库水印绑定、启停和顺序。用户自行提供毛子ERP Token及Ozon Client ID/API Key。
- 利润、图片分数、物流、库存、补充间隔、验收上限配置；暂停只停止新增，已提交商品仍回查。
- 四个模块插槽；支持管理员注册HTTPS服务或服务器预安装的Python插件。[模块协议](docs/MODULE_PROTOCOL.md)。
- 当前毛子原生上架与Ozon直连回查；先创建、再写指定仓库库存、最后核验可售与库存。没有模拟结果冒充真实成功。
- SQLite WAL持久任务、租约恢复、固定商品幂等键、单写入者、错误退避、额度轮转、明确禁止上架清单。
- 商品列表、原图/1688对比、相似度、利润、店铺、清晰失败原因。只有管理员可看脱敏故障记录。

## 保护源码和日志的边界

浏览器只获取界面资源和当前用户可见数据，不提供后端Python、原始日志、密钥文件或OpenAPI调试页。密码scrypt哈希，连接密钥Fernet加密，主密钥仅存服务端私密目录。应用所有者/服务器管理员仍可读取自己的部署文件；无法同时把完整服务器交给别人，又保证机器所有者绝对看不到代码。正式交付优先部署在你控制的服务器。

## 服务器部署

提供Dockerfile与compose.yaml；服务器使用HTTPS反向代理公开Web入口，worker不开放端口。`FLOWHUB_HTTPS=1`开启安全Cookie，compose仅将8000绑定服务器回环地址，必须配置TLS反向代理后登录。生产必须备份完整data卷（数据库和master.key一起），定期做恢复演练。Docker部署配置尚未在远程服务器现场验收。

## 验收状态

权限隔离、源代码/密钥不可下载、改密注销旧会话、完整模拟闭环、上架/库存已执行但响应丢失后的重启恢复、禁止清单、额度切换、缺失模块等均有自动测试。

用户明确要求**真实店铺真实上架验收**：本机管理员已配置丽丽一号，规则70/55、邮政成本利润率>30%、库存99。首轮最多3件真实提交。原FlowEF发布器在移交时暂停，源SKU共用永久占用保护。当前进度见 `data/live-acceptance.json` 和软件中的真实任务，不能把模拟测试或接口accepted当作真实可售。

连续24小时稳定运行需要跑满24小时；未完成前不能宣称已通过。短测试覆盖了重启、未知写入、幂等和权限，但不能代替运行时间证明。
